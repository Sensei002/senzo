# SENZO roadmap

This roadmap is intentionally staged. A feature is not considered complete until it is implemented, tested, and documented on both supported desktop platforms where applicable.

## Phase 0 — Foundation

- [x] Initialize repository and branch strategy.
- [x] Add the first native GPUI application shell.
- [x] Establish the initial brand mark and wordmark as scalable SVG assets.
- [ ] Verify Windows and Linux CI builds.
- [ ] Add automated formatting, lint, and test checks.

## Phase 1 — Desktop experience

- [ ] Application window, navigation, and responsive layout.
- [ ] Design tokens, typography, reusable controls, and empty states.
- [ ] Home, search, library, detail, and settings screens.
- [ ] Keyboard navigation and accessibility baseline.

## Phase 2 — Local foundation

- [ ] Domain models and SQLite schema/migrations.
- [ ] Settings and local library persistence.
- [ ] Playback history and resume positions.

## Phase 3 — Playback and discovery

- [ ] MPV integration behind a playback abstraction.
- [ ] Subtitle and audio-track controls.
- [ ] Metadata provider adapter.
- [ ] Add-on protocol investigation and first compatible source adapter.

## Phase 4 — Advanced media sources

- [ ] Torrent engine evaluation and proof of concept.
- [ ] Buffering, seeking, and source health reporting.
- [ ] Discord Rich Presence and privacy controls.

## Phase 5 — Distribution

- [ ] Windows and Linux packaging.
- [ ] Stable and Development update channels.
- [ ] Signed update metadata and artifact verification.
- [ ] Release notes and rollback-safe update flow.
